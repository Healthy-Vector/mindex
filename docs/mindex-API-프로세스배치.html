PostgreSQL 17 · main의 P2-DB 계약 · legal right × exploitation mode 2축 기준

DB 정본은 P2-DB의 sql/init/*.sql이다. 도메인은 public, 임시 추출은 같은 DB의 staging 스키마를 사용한다. 충돌은 rights_grant 행이 아니라 contract_history.status='conflicted'와 conflict_report로 기록한다.

request  { "pin": "1234" }

5POST/api/contracts/verify계약 검증
공개 · 200

권리마다 legalRight와 exploitationMode를 모두 받는다. rights·territories는 한 건 이상이다.

request {
  "contractId": null, "grantor": "C사", "grantee": "T사", "ipId": 12,
  "fileName": "contract.pdf", "filePath": "contracts/...", "fileHash": "...",
  "documentKind": "draft",
  "rights": [{
    "contentAssetId": 80, "legalRight": "TRANSMISSION", "exploitationMode": "SVOD",
    "territories": ["APAC"], "period": {"start":"2027-01-01","end":"2027-12-31"},
    "exclusivity": "exclusive", "evidence": { "legal_right":{"quote":"..."}, "exploitation_mode":{"quote":"..."}, "territory":{"quote":"..."}, "period":{"quote":"..."}, "exclusivity":{"quote":"..."} }
  }]
}
response { "batchResult":"CONFLICTED", "hasConflict":true, "constraintName":"no_exclusive_overlap", "conflictReport":{...} }

validate_rights_batch()가 실제 INSERT 경로로 판정하고 내부 쓰기를 전부 되돌린다.

6POST/api/contracts확정 저장
공개 · 201

5번 요청에 선택 chunks[]와 sourceTmpid를 추가한다. 청크 페이지는 pageStart·pageEnd로 보내며 단일 page는 사용하지 않는다.

response {
  "batchResult":"APPLIED", "contractId":101, "contractHistoryId":301,
  "hasConflict":false, "constraintName":null, "conflictReport":null
}
  • sourceTmpid가 있으면 staging 작업이 DONE이고 extract_result가 있어야 하며, 현재 사용 중인 값의 재사용은 409 ALREADY_CONFIRMED.
  • 충돌이어도 201이며 grant는 0행, conflicted history와 P2 conflict_report는 커밋.
  • consumed_at·TTL 정리는 D-33 O-15 확정 전 별도 단계.
  • 과거 개정 tmpid까지 영구 차단하려면 P2에 history 단위 UNIQUE 또는 소비 원장이 필요하다.
7GET/api/contracts통합 목록
공개

query: includeProcessing=true, page, size. 계약과 staging의 QUEUED/RUNNING/FAILED 항목을 최신순으로 섞어 {items,total,page,size}로 반환한다. 계약 표시는 최신 fileName을 쓴다.

8GET/api/contracts/{id}계약 상세
Bearer 필요

기본정보, ips, active rights, histories, 최신 conflictReport를 한 번에 반환한다. 권리는 legalRight·exploitationMode와 각각의 라벨을 포함한다. 충돌 세대에는 grant가 없으므로 입력 충돌은 histories의 report에서 읽는다.

9GET/api/contracts/{id}/file원본 PDF
Bearer 필요

contract_history.file_path의 PDF를 반환한다. 현재 구현은 로컬 파일 어댑터이며 object storage 연결은 남은 통합 작업이다. 없으면 404 NO_SOURCE_FILE.

10GET/api/rights/{lineageId}/history권리 계보
Bearer 필요

active·terminated 세대를 오래된 순서로 반환한다. 각 generation은 contractHistoryId·version, legalRight, exploitationMode, territory, 기간, exclusivity, 종료정보와 서버 계산 changedFields를 포함한다.

11POST/api/contracts/{id}/cancel계약 종료
Bearer 필요

request body 없음. contract를 cancelled로 바꾸면 P2 트리거가 active grant를 terminated/cancelled로 내린다.

{ "contractId":101, "status":"cancelled", "terminatedRights":4, "terminatedAt":"..." }

없는 계약은 404, 이미 종료된 계약은 422 ALREADY_CANCELLED.
